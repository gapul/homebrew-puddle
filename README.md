# homebrew-puddle

Homebrew tap for **Puddle** — a personal, telemetry-free FOSS fork of
[Plash](https://github.com/sindresorhus/Plash) (which went closed source),
forked at its last MIT-licensed commit. Makes any website your Mac desktop wallpaper.

```sh
brew install --cask gapul/puddle/puddle
```

- App source (private): https://github.com/gapul/Puddle
- Signed with Developer ID and notarized by Apple.
